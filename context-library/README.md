# context-library

- **What goes where:** `strategy/` holds the brief; `prds/`, `research/`, `decisions/`, `launches/`, `metrics/`, `meetings/` hold finished work the PM moves here from `outputs/`.
- **Who writes here:** skills read from this folder and write every new document to `outputs/`. Only the PM moves files in.
- **Start here:** read `strategy/brief.md`, then fill `business-info-template.md`.

## Names policy

Set by the PM in the project `CLAUDE.md` (2026-10-25), copied here so `/name-audit` finds it.

- **Synthetic, invented names only** for the LP, its funds, managers, companies, people and letters.
- **Never named:** the PM's employer, clients, prospects or interview targets. No real organisation is ever "the LP". No real investor's name sits next to a synthetic fact.
- **Named and linked:** public sources that back a number or a technical claim (academic papers, docs and licences of open-source tools, public statistics, public pension disclosures cited as background).
- **Disclaimer on every user-facing surface:** "Synthetic data. Not investment advice."
